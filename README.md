# Registration Form

A simple and responsive registration form built using HTML and CSS.  
This project focuses on clean UI design and proper form structure.

## Features

- User-friendly registration form layout
- Responsive design for different screen sizes
- Structured form fields (Name, Email, Password, etc.)
- Clean and modern CSS styling

## Technologies Used

- HTML5
- CSS3

 ## How to Run

1. Download or clone this repository
2. Open index.html in your web browser
